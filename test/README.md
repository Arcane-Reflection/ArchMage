# test — QEMU harness and fixtures

Headless boot/SSH smoke tests for built images (Phase 1, plan 01-02) plus
shared fixtures. `fixtures/pacman-verify.conf` (added in 01-01) verifies
the CI staging-repo artifact signatures locally.

## desktop-x86_64.sh — desktop image builder (two modes)

`desktop-x86_64.sh` builds the ArchMage desktop x86_64 image (GPT: ESP +
btrfs `@`/`@var`/`@snapshots`, snapper preconfigured):

- **default — Omarchy base (D-0, 2026-11-11)**: installs the version-pinned
  Omarchy 4.5.x stack from `[omarchy] https://pkgs.omarchy.org/stable` plus
  the CN/brand overlay (`archmage-desktop` + `archmage-branding`). The pin
  lives in `test/omarchy-version.txt` (`<pkgver>-<pkgrel>` of the `omarchy`
  meta package; bump deliberately — it is the upstream-drift breakwater).
  Boot path: limine (ESP mounted at `/boot`, entries generated by
  `limine-mkinitcpio`, OVMF boots `\EFI\BOOT\BOOTX64.EFI`), SDDM autologin
  into the branded uwsm Hyprland session. 33 structural gates.
- **`--legacy` — pre-D-0 builder**: bare Arch + hand-rolled Hyprland, GRUB +
  greetd. Kept verbatim for builder rollback/comparison. 18 gates.

The omarchy keyring chicken-and-egg is broken deterministically by the shared
script `test/omarchy-keyring-bootstrap.sh` (fetch the repo db over HTTPS, read
`omarchy-keyring`'s FILENAME/SHA256SUM from the db, verify the package against
the db entry, extract into `/usr/share/pacman/keyrings/`, then
`pacman-key --populate omarchy`). The packages.yml x86_64 build container runs
the same script so `makepkg --syncdeps` can resolve omarchy-base dependencies;
the root check sits at the end so the fetch/verify chain is testable
unprivileged.

Local rebuild (Linux host or docker): `ARCHMAGE_DESKTOP_MIRROR_ORDER=cn
bash test/desktop-x86_64.sh --from-ci` (~20–40 min/round).

### Differential builds on the packages pipeline (CI note)

The CI build container resolves cross-package deps through a throwaway
`[archmage-local]` repo (`Server = file://…`). `repo-add` only indexes files
in place — it does NOT copy them — so every indexed package file must also be
copied into the repo dir, or `pacman -S` in a later `makepkg --syncdeps`
fails instantly on the file:// fetch. Two seeding paths depend on this: the
cache seeding (differential builds whose leaves are cache-only, never
installed into the ephemeral container) and the in-loop install of freshly
built packages.

### boot-verify-x86_64.sh — D-0.3 boot verification (CI job context)

`desktop-boot-verify` (image.yml) downloads the fresh desktop artifact and
runs this script inside an archlinux:base-devel container: pacman installs
qemu-system-x86 + edk2-ovmf + imagemagick (the proven pacman channel — the
apt channel stalled on the ubuntu-26 runner migration), then QEMU boots the
image headless: OVMF(4m) -> limine fallback EFI -> linux-omarchy -> SDDM
autologin -> Hyprland. QMP screendumps run on a settle loop (first frame
60s, then every 30s for ~10 min — TCG, no KVM on runners) and the gate is a
non-black final frame (mean luminance >= 2/255, the D-0.3 grim-nonblack
contract measured from outside the VM). Frames + serial tail ship as the
desktop-boot-screens artifact and ride the nightly release.

Two archlinux-specific notes: edk2-ovmf ships only the 4M flash variants
(`/usr/share/edk2-ovmf/x64/OVMF_{CODE,VARS}.4m.fd`), and qemu runs with
`-accel tcg,thread=multi` since hosted runners expose no KVM.
