# test — QEMU harness and fixtures

Headless boot/SSH smoke tests for built images (Phase 1, plan 01-02) plus
shared fixtures. `fixtures/pacman-verify.conf` (added in 01-01) verifies
the CI staging-repo artifact signatures locally.

## desktop-x86_64.sh — desktop image builder (two modes)

`desktop-x86_64.sh` builds the ArchMage desktop x86_64 image (GPT: ESP +
btrfs `@`/`@var`/`@snapshots`, snapper preconfigured):

- **default — Omarchy base (D-0, 2026-11-11)**: installs the version-pinned
  Omarchy 4.5.x stack from `[omarchy] https://pkgs.omarchy.org/stable` plus
  the CN/brand overlay (`archmage-desktop` + `archmage-branding`). The pin
  lives in `test/omarchy-version.txt` (`<pkgver>-<pkgrel>` of the `omarchy`
  meta package; bump deliberately — it is the upstream-drift breakwater).
  Boot path: limine (ESP mounted at `/boot`, entries generated by
  `limine-mkinitcpio`, OVMF boots `\EFI\BOOT\BOOTX64.EFI`), SDDM autologin
  into the branded uwsm Hyprland session. 33 structural gates.
- **`--legacy` — pre-D-0 builder**: bare Arch + hand-rolled Hyprland, GRUB +
  greetd. Kept verbatim for builder rollback/comparison. 18 gates.

The omarchy keyring chicken-and-egg is broken deterministically: fetch the
repo db over HTTPS, read `omarchy-keyring`'s FILENAME/SHA256SUM from the db,
verify the package against the db entry, extract into
`/usr/share/pacman/keyrings/`, then `pacman-key --populate omarchy`.

Local rebuild (Linux host or docker): `ARCHMAGE_DESKTOP_MIRROR_ORDER=cn
bash test/desktop-x86_64.sh --from-ci` (~20–40 min/round).
